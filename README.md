# Noor — Stories of the Prophets (starter app)

This is a responsive, installable web-app prototype designed to be the first version of Noor. It is **not yet a native Android package and is not published on Google Play**.

## What's included
- Responsive home screen and story detail screens
- English, Urdu and Hindi interface/story summaries
- Quran reference ranges for four sample story guides
- Quran-first editorial policy notice
- Donation information placeholder (no payments)
- Basic web-app manifest and service worker

## Important religious-content review
The included material is a research starter, not a final religious script or scholarly certification. Before publication:
1. Check each claim against the cited Quran passage and reliable tafsir.
2. Add a Hadith only after checking the original source, exact reference, grading and context.
3. Clearly separate Quranic facts from supplementary Hadith.
4. Omit fabricated/unsupported details and avoid inventing dialogue, dates, places or physical descriptions.
5. Have a qualified scholar review the final English, Urdu and Hindi scripts.
6. Check translations for meaning, not merely literal word matching.
7. Do not depict prophets' faces or portray prophets visually.

## Try it on your Android phone
For a quick local preview, open `index.html` in a browser or upload the project to a static hosting service. Service-worker/offline installation works only when served over HTTPS or localhost; opening the file directly may not enable installation. Do not enter private credentials into third-party builders.

## Suggested next steps
1. Put the files in a GitHub repository you control.
2. Publish as a free static web preview (for example, using GitHub Pages).
3. Test language switching, Arabic/Urdu text direction, accessibility and small-screen layouts.
4. Build a native Android wrapper or Flutter implementation for Play Store distribution; generate a signed Android App Bundle (.aab), test it, and submit it through your own Play Console.
5. Add privacy policy, data-safety declarations, content rating, app icon/screenshots and donation flow only after reviewing current Play policies.

## Planned app identity
- Working title: Prophets Of Islam
- Suggested Android package ID: `org.ProphetsofIslam.app` (confirm availability before release)
- Initial audience: family-friendly, English/Urdu/Hindi
- Monetization: voluntary support; no payment integration in this prototype

## Budget note
Google Play Console currently charges a one-time US$25 registration fee, in addition to any applicable currency conversion/taxes. This alone may consume much of the initial budget. Hosting can be free at prototype scale; avoid paid tools until the app scope is tested.
