# Noor content review checklist

For each story, maintain a claim-by-claim source ledger.

| Field | Required |
|---|---|
| Claim / script sentence | Exact claim used in the narration |
| Primary Quran reference | Surah and ayah, or mark as supplementary |
| Quran translation/tafsir consulted | Name and edition/version |
| Hadith source | Collection, book/chapter, hadith number where available |
| Hadith grading | Source and scholar/grading reference |
| Classification | Quran / authentic Hadith / interpretation / omitted |
| Scholarly review | Reviewer, date, changes requested |
| Translation review | English, Urdu, Hindi checked independently |
| Visual review | No depiction of any Prophet; no invented historical detail |
| Release status | Draft / reviewed / approved |

## Rules
1. Quran is the primary source; do not use a report to override a clear Quranic statement.
2. Investigate apparent conflicts in context; do not judge authenticity from a paraphrase.
3. Hadith is supplementary only after its authenticity, context and interpretation have been checked.
4. Do not present weak, fabricated, Isra'iliyyat, or disputed reports as established facts. If an educational mention is essential, label its status clearly and obtain scholarly review.
5. Do not invent dialogue, chronology, geography, clothing, architecture or physical features.
6. Do not visually depict Prophets. Use landscapes, objects, calligraphy and abstract transitions.
7. Do not reproduce copyrighted Quran translations without checking permissions/licensing.
8. Cite references in a way users can verify; do not imply scholar approval before it exists.
